# ContextSpace 2.10.1 release notes

The desktop application, Windows installer/uninstaller, and fallback web icons
now use the current ContextSpace C mark. The 2.10.0 release still included the
older CW raster artwork. The desktop window icon is now included in the packaged
application, and a generation command keeps the raster assets aligned with the
current SVG source.

Installation paths, application identity, and existing user profiles are unchanged.
