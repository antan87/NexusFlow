# ContextSpace 2.13.0

This release makes workspace skills selectable and gives larger projects a durable
place for delivery planning, questions, and existing-work evidence.

- Workspace-local skills can be enabled and saved. The Skills tab reports invalid
  packages, missing catalog sources, and duplicate IDs, and respects explicit selection.
- Delivery notes and questions live in `contextspace-milestones.md`, survive refresh,
  and can be edited from Plan. Conflicting saves preserve your draft.
- Milestones can name a repository, work item or PR, and unblock condition. Circular
  package dependencies now use release-coordination guidance instead of an impossible
  implementation order.
- Desktop-created workspaces get local CLI launchers and MCP configurations for the
  selected assistants. Windows freshness warnings distinguish known changes from
  snapshots that cannot be verified safely.
- Branch activity uses absolute timestamps and filters dependency-bot branches.
  Development skills and documented-command validation are improved.

## Upgrading

Refresh existing workspaces after installing 2.13.0. If `ctxspace` is not on PATH,
use `./.contextspace/bin/ctxspace` in a refreshed workspace, or
`.\.contextspace\bin\ctxspace.cmd` in PowerShell. Antigravity MCP configuration remains
user-level; the local CLI is available.

The old generated plan's appended `## Milestones` section is imported into delivery
notes automatically. Move other manually authored sections into the authored document
before refreshing. Authored `.agents/skills` files are preserved when deselected;
assistants that scan that folder directly may still discover them.

See [documents and work guidance](https://github.com/antan87/NexusFlow/blob/v2.13.0/docs/work-guidance.md) for supported behavior.
