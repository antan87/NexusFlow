# ContextSpace 2.10.0 release notes

ContextSpace is the new product name for NexusFlow. This release adds workspace
Workrooms for assistant handoffs, refreshed chat harness/model selection, and
floating workspace chat. Narrow windows now use a navigation drawer so workspace
content remains usable.

## Installation and compatibility

- Install or update with `npm install -g @mrpatronz/nexusflow`. The npm package name
  stays unchanged; `ctxspace` is the primary command and `nexusflow` remains an alias.
- Node.js **22.13.0 or newer** is required.
- The VS Code extension requires VS Code **1.125.0 or newer**. Stable GitHub Releases
  include `ContextSpace.vsix` for manual installation using **Extensions: Install
  from VSIX…**. Marketplace delivery depends on repository publishing configuration.
- Windows NSIS and Linux x64 AppImage are the supported desktop release targets.
  The Windows application ID stays stable. Existing NexusFlow desktop profiles are
  reused when no ContextSpace profile exists; existing Linux CLI-managed installs
  retain their launcher and install directory.

## Reliability fixes

The extension now registers MCP definitions with the supported VS Code API, runs
sidebar actions under its content security policy, packages its icons and license,
opens the actual workspace context files, and executes CLI arguments without shell
interpolation. Dashboard startup failures provide installation/recovery guidance.

Dependency audit findings were resolved across the CLI, GUI, desktop, and extension.
The security workflow now rejects findings at every severity. Published npm packages
exclude compiled tests, and CI verifies that the extension can produce a VSIX.
